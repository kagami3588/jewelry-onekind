# TG訪問営業チーム 月次実績レポート：項目と型

元ファイル: Google Sheets「sep2026_月次実績レポート_完全修正版」
シート: サマリー（印刷用）
方針: 評価のためではなく、各自が先月と今月の自分を比べ、来月の変え方を考えるための資料。

## 毎月提供してもらう入力数字
個人ごとに今月・先月の各数値:
- 訪問数 / IF越し数 / 対面数 / 客宅・会社説明数 / アポ獲得数 / キャンセル数
- 月間目標（現状は 13件/人）、データ取得期間、活動者数

## 導出式（型）
| 指標 | 式 |
|---|---|
| 在宅率 | IF越し ÷ 訪問数 |
| 対面率 | 対面数 ÷ IF越し |
| 客宅率 | 客宅・会社説明 ÷ 対面数 |
| アポ率 | アポ獲得 ÷ 客宅・会社説明 |
| 総合移行率 | アポ獲得 ÷ 訪問数 |
| 有効アポ | アポ獲得 − キャンセル |
| 達成率 | 有効アポ ÷ 月間目標 |
| 先月比 | 件数は差（+189件）、率は pt 差（+1.0pt）、符号付き |

表記: 件数は「1,049件」（桁区切り+件）、率は小数1桁の%、増減は「+1.0pt」、変化なしは「±0」。
全体の増減欄は小数2桁（1.30 / -0.50）。

## サマリー（印刷用）の構成
1. タイトル「TG訪問営業チーム 月次実績 2026年9月（9/1〜9/29）」
2. ■ このデータを出している目的（評価ではない旨の文章）
3. ■ 基本情報: データ取得期間 / 参照人数（活動者 6名）/ 今月のアポイント結果（23件）/ 月間目標 / キャンセル数
4. ■ 今月と先月の全体数字の詳細（チーム合計、訪問→アポ獲得）
   - 列: 指標 / 件数（チーム合計）/ 移行率 / 意味
   - 行: 訪問数（ピンポンを押した件数）/ IF越し（在宅を確認できた件数）/ 対面数（扉を開けてもらえた件数）/ 客宅・会社説明（会社説明まで進んだ件数）/ アポ獲得数 / キャンセル数（アポ後のキャンセル数）/ 有効アポ（アポ獲得−キャンセル）
5. ■ 今月の全体移行率（チーム平均）
   - 列: 移行率の種類 / 今月 / 先月 / 増減 / 説明
   - 行: 在宅率 / 対面率 / 客宅率 / アポ率 / 総合移行率（訪問1件あたりのアポ獲得確率）
6. ■ 今月の個人データ
   - 列: 名前 / 有効アポ・訪問数・対面数・客宅数・アポ獲得・cancel / 在宅率・対面率・客宅率・アポ率・総合移行率・達成率 / 先月比（有効アポ・訪問数・在宅率・対面率・客宅率・アポ率）
   - 1人1行、名前は団体内の氏名
7. ■ 先月の個人データ（同じ列、先月比を除く）

## 対象範囲
サマリー（印刷用）のみ。振り返りフォームは対象外。
